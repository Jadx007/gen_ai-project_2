# 🤖 JadBot – AI Chatbot and Image Generator

## 1. Project Description
JadBot is an AI-powered application that can answer user questions and generate images from text prompts. It combines a chatbot and an image-generation model in one application.

## 2. Main Features
- **Question Answering:** Answers questions entered by users.
- **Image Generation:** Creates images based on text descriptions.
- **Multilingual Support:** Can process multiple languages depending on the models used.
- **User-Friendly Interface:** Allows users to interact easily with the application.

## 3. Technologies Used
- Python – Programming language.
- Hugging Face – Provides pretrained AI models.
- Transformers – Helps run language models.
- Diffusers – Helps generate images.
- PyTorch – Supports deep learning.
- Gradio – Creates the web interface.
- Google Colab – Provides the development environment.

## 4. How It Works
1. The user enters a question or image prompt.
2. JadBot identifies the type of request.
3. For questions, the chatbot model generates an answer.
4. For image prompts, the image-generation model creates an image.
5. The result is displayed on the screen.

## 5. Example
**Question:** What is Artificial Intelligence?

**Answer:** Artificial Intelligence enables computers to perform tasks that usually require human intelligence.

**Image Prompt:** A cute Pikachu in a colorful garden.

**Result:** JadBot generates an image based on the prompt.

## 9. Installation and Execution
1. Open the project in Google Colab.
2. Install the required Python libraries.
3. Load the question-answering and image-generation models.
4. Run the Gradio application.
5. Enter a question or image prompt and view the result.

## 10. Conclusion
JadBot demonstrates how Artificial Intelligence can answer questions and generate images in a single application. It provides a simple way to explore conversational AI and image generation.
